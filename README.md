EduEvent - Plateforme événementielle du CHCL

Présentation

EduEvent est une plateforme web statique conçue pour le Campus Henry Christophe de Limonade (CHCL). Elle centralise l'ensemble des événements universitaires : conférences, soutenances, compétitions sportives et activités culturelles.

Objectif

Permettre à la communauté universitaire (étudiants, professeurs, personnel) de :

- Découvrir tous les événements du campus en un seul lieu
- S'inscrire aux événements gratuitement ou avec paiement
- Gérer ses inscriptions et ses billets depuis un espace personnel
- Interagir via les commentaires

Fonctionnalités

Pour tous les visiteurs

- Consultation des événements avec filtres (catégorie, date, prix)
- Recherche par mot-clé
- Page de détail avec description, programme et compteur
- Inscription ou connexion

Pour les utilisateurs connectés

- Espace personnel avec photo de profil
- Gestion des inscriptions (annulation, suivi)
- Billets téléchargeables
- Modification des informations personnelles

Technologies

- HTML5, CSS3, JavaScript (ES6+)
- Stockage local (localStorage)
- Architecture statique sans serveur
- Responsive design (mobile-first)

uide d'utilisation

Navigation

- Accueil : Présentation du site et événements à la une
- Événements : Liste complète avec filtres et recherche
- À propos : Mission, équipe, contact, FAQ
- Mon espace : Profil, inscriptions, billets (connexion requise)

Inscription / Connexion

1. Cliquer sur "S'inscrire" ou "Se connecter"
2. Remplir le formulaire
3. Les données sont sauvegardées dans le navigateur

Gestion des inscriptions

1. Se connecter à son espace
2. Onglet "Mes inscriptions" : visualiser, annuler
3. Onglet "Mes billets" : télécharger en HTML

Filtres des événements

- Catégorie : Conférence, Sport, Culture, Soutenance, Soirée
- Période : Aujourd'hui, Cette semaine, Ce mois
- Prix : Gratuit, Payant
